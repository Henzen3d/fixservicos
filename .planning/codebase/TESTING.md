# Testing

## Testing Strategy
Currently, there is no automated testing framework in place.

## Manual Verification
- **SEO Validation**: Spreadsheets are used to manually cross-reference URLs with their intended SEO meta data.
- **Asset Integrity**: Visual verification of service images in `Servicos Blumenau/`.
- **Link Integrity**: Check `linktree/index.html` and `avaliar/index.html` for correct URL redirection.
