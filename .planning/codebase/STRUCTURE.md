# Structure

## Directory Layout

- `root/`
  - `_public_html.zip`: Main site backup (2GB).
  - `llms.txt`: Comprehensive business and site documentation.
  - `*.xlsx`, `*.csv`: SEO data spreadsheets (H1, H2, Titles, Descriptions).
  - `robots.txt`, `sitemap.xml`: SEO meta files.
  - `license.txt`, `readme.html`: WordPress core remnants.
  - `Referencias/`:
    - `Modelos_Sites.md`: Visual and functional references.
    - `SEO_master.csv`: Master SEO mapping.
  - `Servicos Blumenau/`:
    - Service-specific images (Instalacao-Ar-Condicionado, Limpeza-CAIXA-DE-AGUA, etc.).
  - `avaliar/`:
    - `index.html`: Review landing page.
    - Review-related images.
  - `linktree/`:
    - `index.html`: Link aggregator page.

## Naming Conventions
- **Images**: Descriptive, Portuguese, hyphenated or underscored (e.g., `Instalacao-Ar-Condicionado_Blumenau.jpg`).
- **Data**: Descriptive prefixes for SEO data (`h1_all.xlsx`, `meta_description_all.xlsx`).
