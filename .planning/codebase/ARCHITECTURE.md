# Architecture

## System Design
The current project state is a **pre-development asset repository**. It centralizes SEO data, reference models, and legacy site backups to inform a redesign.

## Key Components
1. **SEO Knowledge Base**: `Referencias/` and root `.xlsx`/`.csv` files form the informational core of the project.
2. **Asset Library**: `Servicos Blumenau/` and `avaliar/` store visual assets categorized by service or function.
3. **Legacy Backup**: `_public_html.zip` serves as the source of truth for the previous implementation.
4. **Landing Stubs**: `linktree/` and `avaliar/` provide minimal functional entry points.

## Data Flow
- **SEO Data** -> **Redesign Strategy**
- **Legacy Assets** -> **New Site Implementation**
